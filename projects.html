01

MUSSA Online Voting System

Deployed

My dissertation project: a full online voting platform built for Makerere University Students' Association elections. It includes a two-tier role model separating system administration from election-commission administration, a ballot-secrecy-preserving audit trail with CSV, Excel, and PDF export, and a public results page that switches state automatically as an election opens and closes. Security hardening included environment-based secrets, OTP attempt limiting, and admin IP throttling.

Django PostgreSQL Self-hosted CSS system Dark mode

RHU Katego Clinic — Store Inventory Management System

In progress

A web-based inventory management system built for a reproductive health clinic in Kampala, currently in development. It spans eleven Django apps and thirty-seven templates, with Excel export handled through openpyxl and an accompanying software requirements specification document.

03

Verified Centralized Statistical Data Repository (VCSDR)

Group project

An 18-member Makerere group project to build a verified repository for statistical data, rebuilt from an original PHP/MySQL version into Django and PostgreSQL with a custom Makerere-green design system replacing Bootstrap. I worked across both the Programmer and Database Admin & Security teams, including customising Django's native admin interface and writing team compliance documentation.

Django PostgreSQL Team project
04

Makerere Actuarial Society Website

Static site

A static Home / About / Activities / Contact / Leadership site for the Makerere Actuarial Society, built in plain HTML, CSS, and JavaScript for hosting on Cloudflare Pages. It links out to a separate Django-based voting system for society elections, with a JavaScript check that confirms the voting site is reachable before sending visitors there.
